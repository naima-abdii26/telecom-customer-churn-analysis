# Telecom Customer Churn & Subscription Optimization

## Project Overview
This project analyzes 1,000 telecom subscriptions to identify churn patterns across subscription plans, service types, customer locations, and age groups.

## Tools Used
- **MySQL:** Data profiling, cleaning, joins, and business analysis.
- **Microsoft Excel:** Power Query, data quality checks, PivotTables, and churn-rate analysis.
- **Microsoft Power BI:** Interactive dashboard development — **In Progress**.

## Key Findings
- **Overall churn:** 236 of 1,000 subscriptions (23.60%).
- **Highest plan churn:** Mobile Data 5GB — 37.89%.
- **Highest service-type churn:** Data Only — 32.11%.
- **Highest location churn:** Bosaso — 30.82%.
- **Age groups:** Churn rates were similar across the analyzed groups.

## Business Considerations
These findings identify patterns in the available dataset but do not establish the causes of churn. 
Monthly charges associated with churned subscriptions should not be interpreted as confirmed future revenue losses.
